Manual de instalación: SQL Server 2019 y CONTPAQi

1. Desinstalar Todos los programas de SQL y CONTPAQi

Desinstalar Todos los programas de SQL y CONTPAQi instalados.

Utilizar la herramienta de Geek y quitar los rastros del programa en cada programa desinstalado.

Descargar Geek

2. Activar Framework 3.5

Ingresar a cmd y ejecutar como administrador y pegar esto:

DISM /Online /Enable-Feature /FeatureName:NetFx3 /All

Si aún no lo activa o aparece un error probar con este comando:

DISM /Online /Enable-Feature /FeatureName:NetFx3 /All /LimitAccess /Source:X:\sources\sxs

3. Instalar SQL Server 2019

Descargar SQL Server 2019
  1. Ejecutar el archivo descargado SQL2019-SSEI-Expr.exe y seleccionar Download Media, seleccionar idioma y donde lo descargara y dar en download (lo guardará en descargas)
  2. Extraer el archivo SQLEXPR_x64_ESN.exe
  3. Crea una carpeta SQLEXPR_x64_ESN, entra y ejecutar SETUP
  4. Nueva instalación independiente de SQL Server o agregar características a una instalación existente
  5. Aceptar términos de licencia y declaración de privacidad y siguiente
  6. No Usar Microsoft Update para comprobar actualizaciones (dejar desmarcada la casilla)
  7. Características de instancia no mover y siguiente
  8. Nombra la instancia como deseen pero que no sea como instancias anteriores, en instancia con nombre, COMPAC2019 siguiente
  9. En el apartado de SQL Server Browser en el tipo de inicio seleccionar automático. Siguiente
  10. En el modo de autenticación poner modo mixto (autenticación de SQL Server y de Windows), escribir una contraseña sencilla y que no se olvide y confirmarla,
  11. En la especificación de los administradores de SQL Server, seleccionamos el botón de agregar y en el nombre del objeto escribimos “todos” y aceptar, abrirá una ventana donde seleccionamos Todos y luego seleccionamos TODOS EN EL aceptar y
  12. Seleccionamos de la lista \Todos (Todos) luego siguiente
  13. Esperamos a que termine la instalación y todo debe estar correcto luego cerrar.

Configuración de red de SQL Server

  1. Abrir Administrador de configuración de SQL Server.
  2. Expandir la sección Configuración de red de SQL Server, seleccionar el protocolo de y el nombre de la instancia en este caso “COMPAC2019”
  3. Del lado derecho seleccionar TCP/IP que esta como Deshabilitado y clic derecho y Habilitar y aceptar, igual con el proceso de Canalización con nombre.
  4. Luego vamos a Servicios de SQLServer Buscamos SQL Server (COMPAC2019), clic derecho y propiedades y damos Iniciar sesión como: Cuenta integrada y seleccionamos Sistema local luego aplicar y ¿Desea continuar? Si y luego aceptar.
  5. Seleccionamos Ahora SQL Server Browser Clic derecho y reiniciar.
  6. Cerrar todo y podemos instalar CONTPAQi

Windows no pudo iniciar el servicio SERVIDOR CONTPAQi

SOLUCIÓN:

  • Ir a Inicio/Ejecutar/Regedit
  • Ir a HKEY_LOCAL_MACHINE > SYSTEM > CurrentControlSet > Control
  • Con la carpeta de control seleccionada, haga clic derecho en el panel de la derecha y seleccione nuevo > Valor de DWORD
  • Nombra el nuevo DWORD: ServicesPipeTimeout
  • Haga clic en con el botón derecho en ServicesPipeTimeout y luego clic en modificar
  • Haga clic en Decimal, escriba '180000'
  • Guardar y cerrar el Regedit
  • Reiniciar equipo y verificar el servicio inicie correctamente.
